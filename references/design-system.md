# 极简天文学演示设计系统 v1.0

> 以下为 **本 Skill 的推荐值**，而非天文学学会强制统一标准。针对 16:9、1080p 会场、演讲而非纸质阅读。

## 1. 几何

- 画布：宽 `13.333 in` × 高 `7.5 in` (16:9)。设计参照 1920 × 1080 px。
- 左右安全边距：0.55–0.75 in；顶部 0.4–0.6 in；底部 0.35–0.5 in。
- 标题内容分区：顶部约 17–22%；正文 70–76%；下方细引用/页码小于 8%。
- 一页主视觉优先约占内容区 50–75%；研究核心大图可以占 80%+。
- 统一对齐线与留白，不使用满页表格和多余装饰分割线。

## 2. 字体

| 元素 | 默认推荐 | 例外 |
|---|---|---|
| 研究标题 | 36–44 pt，通常 2 行以内 | 冗长科学专名可 32–36 |
| 内容页结论标题 | 34–40 pt，最好 1–2 行 | 30–32 |
| 正文/关键结论 | 24–28 pt | 22 可接受 |
| 图表 axes / legends | 18–22 pt | 16 仅次要标签并经全屏验证 |
| 公式符号及注解 | 24–32 pt | 数学复杂时拆页 |
| 来源/图片 credit | 14–16 pt | 必须保证清晰可见，不能因小字造成许可证违规 |
| 页码/辅助标识 | 14–16 pt | 可略去 |

- 中文推荐思源黑体 / Noto Sans CJK / 苹方；英文推荐 Aptos / Arial / Helvetica / Inter / Source Sans 3；Linux 下确认字体可用性。
- 数学字体与数学排版保持一致（原生 Office equation、LaTeX 生成的 SVG/PDF），避免破损或缺符号。
- 普通正文最低优先目标 18pt；主展示文字通常应远大于 18pt。只作为阈值参考，不能拿它作为所有内容默认字号。

| 角色 | HEX |
|---|---|
| background | `#0C1322` |
| title/text | `#F5F8FD` |
| secondary text | `#C5D0E0` |
| accent 1 | `#7DB4F0` |
| accent 2 | `#F1C17A` |
| accent 3 | `#64CEBE` |

- 使用颜色表达数据含义，拒绝为了“太空感”铺满炫光星云、渐变或伪 3D 图标。
- 数据集跨页保持颜色语义不变（如 TESS observation 一直蓝、PHOEBE model 一直橙）；不能让颜色暗示重要性之外的物理关系。
- 同时使用线型/标记形状/直接标注，让图在灰度和色觉差异条件下可辨。
- 正文/背景建议对比度 ≥ 4.5:1；大量关键图和比较差异尽可能有更高对比度。网页 WCAG 大字 3:1 仅为参考下限。

## 4. 版式原型

1. **Opening / Hero**：简洁主标题、作者与单位、会议日期；一张真正相关且有 credit 的天文图（可选）。
2. **Question**：一个科学问题 + 一幅概念图；不是 5 段背景历史。
3. **Data overview**：来源与覆盖范围 + 一张数据展示（时间、波段、采样、样本）。
4. **Method in one diagram**：方法流程 3–5 节点及一个验证节点；复杂算法入 backup。
5. **Observation vs model**：全幅数据图，观测、模型及残差共享 X 轴或并排易比。
6. **Single quantitative result**：最大的科学数字 + 置信区间 + 辅助图。
7. **Comparison / evolution**：两组数据一致尺度对比，标明差值和统计意义。
8. **Interpretation & limits**：左侧直接证据，右侧推断及模型依赖。
9. **Takeaways**：2–3 条用可验证动词写出的结论；未来研究一行即可。
10. **Backup appendix**：详细推导、边界条件、扩展数据、参数表、Q&A 支持图。

## 5. 字数与分镜启发式

- 非图表页正文首选 0–45 中文字 / 0–35 English words，不是硬上限；只有必要的讲义型页面可更多。
- 通常控制 0–3 条 bullet，每条不超过两行；有证据图就尽量让图讲故事。
- 科学术语第一次出现给出 5–12 字或半句解释，但专业听众公认术语可视情况不解释。
- 每页标题 = audience takeaway；若标题大意无法从图得到，应改标题或改图。

## 6. 禁止的常见反例

- 将 LaTeX 论文的全文/Abstract 截图放入页内。
- 将 4×4 panel 的 6pt 出版图整张铺满页面。
- 圆角卡片、emoji、花哨编号、滚动数字、满页渐变的滥用。
- 不标注误差的精确到 7 位的小数或任意扩大 Y 轴差异。
- 绘制没有数据来源的“代表性”拟合曲线并给出科学结论。
- 把被标记为仅示意的轨道几何动画当作真实模型结果。

## 7. 说话与视觉协调

- 讲述句子先说“我们测量了什么”再说“这意味着什么”；要让听众能找到对应的图形位置。
- 每页 speaker notes 包括 1 个开场句、2 个证据句、1 个过渡句，和真实的时长估计。
- 简要逐步显示和视觉局部高亮可以使用，但 PPT/PDF 静态版本仍需完整可读。
