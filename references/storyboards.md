# 天文学报告叙事与时长模板

> 以下每段页数为**本 Skill 推荐启发式**，**不是 AAS/IAU 的通用强制页数**。演讲时间与问答务必分开。

## A. 5 分钟短报告（建议 3–5 页）

| 页 | 预计 | 标题职责 | 视觉 |
|---|---:|---|---|
| 1 | 0:25 | 问题 + 1 句话为何重要 | 相关图像/物理现象 |
| 2 | 1:00 | 观测/数据足以回答问题 | 主光变/谱图 |
| 3 | 1:35 | 最关键的量化证据 | 一张决定性对比图 |
| 4 | 1:10 | 结果物理解释与一个不确定性 | 模型/残差 |
| 5 | 0:40 | 最重要的 2 条结论 | 2 bullets / summary graphic |

总计 ~4:50（留出 10 秒机动）。AAS 常规 contributed oral 可参考官方给定 5 分钟 talk 与 3–5 visual aids，但其他会议规定不同。

## B. 10 分钟专题报告（建议 7–10 页）

| 部分 | 建议分钟 | 要点 |
|---|---:|---|
| Motivation + question | 1:45 | 已知与未知差异；为何值得研究 |
| Data + method | 2:00 | 观测与 1 个关键方法决策 |
| 2–3 results | 4:00 | 每结果一页或一组证据页 |
| Interpretation + limitations | 1:10 | 物理意义、退化和假设 |
| Takeaways | 0:45 | 2–3 个观众能带走的结论 |
| Buffer | 0:20 | 机动 |

## C. 15 分钟研究汇报（默认，建议 10–14 页）

1. Title + one-sentence claim (0:30)
2. Phenomenon / motivation (1:15)
3. Knowledge gap & research question (1:10)
4. Sample / observing program (1:15)
5. Data quality / calibration (1:00)
6. Core method diagram (1:15)
7. Validation / robustness (1:00)
8. Result A: discovery/measurement (1:35)
9. Result B: model vs data (1:35)
10. Result C: model degeneracy / physical inference (1:30)
11. Interpretation / comparison with literature (1:25)
12. Limitations & next steps (0:55)
13. Takeaways (0:40)

合计建议演讲时长约 15 分钟；根据报告内容合并/拆分，目标在严格时间前留几秒到几十秒机动空间。上述各项为大致预算，不是定时脚本。

## D. 30 分钟 invited/colloquium（建议 18–25 页）

- 研究故事通常需要更长背景、更多验证/局限、1–2 处教学式解释。
- 学术团队多、数据多时可用多段 `question → evidence → takeaway`。
- 三个核心结果最多，不是按论文图数遍历；其余备查页。
- 每约 6–10 分钟可设置一个听众能理解的阶段性总结。

## E. 主题分支

### 双星与脉冲星 / 时域报告

叙事：系统类别和物理假说 → 多时段观测 → 周期/轨道信息 → 流量/视向速度证据 → 模型参数/退化 → 物理解释 → 限制。

关键注意：`Pphot` 与 `Porb` 不得混淆；光变主频可呈倍频；系统模型倾角可能受 heating spots / stellar fill factor / dilution 影响。

### 星系、宇宙学报告

叙事：宇宙学/星系形成问题 → 样本及选择函数 → 观测偏差/仪器 → 模型对照 → 统计约束与系统误差 → 物理解释。

### 射电和高能报告

叙事：物理问题 → instrument & observing strategy → calibration / background response → 观测图像与谱/时域图 → 参数拟合与不确定性 → 解释/限制。

### 学位答辩

增加 research landscape、研究贡献对照与发表成果/协作分工，但减少“文献综述逐页讲文章”，强调自己解决什么问题。

## F. 幻灯片标题示例

差：`Results I`、`PHOEBE`、`Discussion`

好：`The strongest signal occurs at half the orbital period`、`A single irradiation model cannot explain both maxima`、`The inclination remains model-dependent`。

这些标题是**写作示例，不代表任何特定天体真实测量结论**；使用前必须由图证支持。

## G. 演讲稿与问答

逐页讲稿不得只是复述坐标/列表，应包含：

1. opening sentence — why this slide matters；
2. evidence — what audience should look at；
3. conclusion — what is supported/not supported；
4. transition — how it answers the next question。

备用页建议包括：data reduction、quality flags、FAP/bootstrapping、alternative models、residual distribution、priors/posteriors、additional bands、referenced comparisons、parameters/definitions。
